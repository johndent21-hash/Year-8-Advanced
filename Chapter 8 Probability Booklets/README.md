# Year 8 Chapter 8 Probability booklets

Built from New Century Maths 8, Chapter 8 (questions rewritten, not copied), aligned to the
NSW Mathematics K–10 Syllabus (2022), Stage 4 MA4-PRO-C-01 only. Stage 5 content (Venn diagrams,
two-way tables, ‘at least / at most’, inclusive/exclusive ‘or’, multistage experiments) is left out of both booklets.

| File | What it is |
| --- | --- |
| `Yr8_Ch8_Probability_Lesson_Booklet.pdf` | Standard student booklet: lessons 1–6 (Easy / Medium / Hard) |
| `Yr8_Ch8_Probability_Lesson_Booklet_Teacher_Copy.pdf` | Same, with notes filled in, answer key and textbook coverage map |
| `Yr8_Ch8_Probability_Extension_Lesson_Booklet.pdf` | Extension booklet: lessons 1–6 (Medium / Hard / Going further) |
| `Yr8_Ch8_Probability_Extension_Lesson_Booklet_Teacher_Copy.pdf` | Extension teacher copy: notes, answer key, coverage map |

Notes and both We do examples are word-for-word the same in both booklets.

Rebuild: see `source/fonts_setup.py` for fonts, then run `source/make_all.sh`
(needs Python 3, Playwright/Chromium, pikepdf, fonttools).
